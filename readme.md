# Castora Web

This folder contains the Castora frontend, a React app that serves the main interface for source review, content analysis, and podcast-oriented workflows.

## Scripts

- `npm start` - run the app in development mode
- `npm run build` - create a production build
- `npm test` - run the test runner
- `npm run eject` - expose the underlying React scripts configuration

## Notes

- The app uses a local proxy to talk to the backend API.
- Install dependencies with `npm install` before starting the frontend.
- Use the root Castora README for full setup instructions and project overview.
